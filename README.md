## About Me

I am a third-year Computer Science student at **Bialystok University of Technology** and a member of **KN ARMUM**. My main interests are embedded systems, IoT, digital electronics, network communication and software that connects low-level hardware with useful applications.

I like projects where I can move between device-side logic, data transport, backend services and clean user-facing functionality. My work includes ESP32-based measurement systems, protocol/API analysis, ASP.NET Core applications and Python tooling.

I also have a game-development background from **Invent Your Game 2021** and **Dżemik Game Jam**.

## Research

**Human presence detection based on analysis of RSSI value changes in Wi-Fi signal in a system with ESP32 modules**

Research work focused on detecting human presence using Wi-Fi RSSI changes measured by ESP32-based modules in a distributed measurement setup.

| Area | Details |
| --- | --- |
| Publication | Elektronika - Konstrukcje, Technologie, Zastosowania |
| Date | 2025-08-29 |
| DOI | [10.15199/13.2025.8.1](https://doi.org/10.15199/13.2025.8.1) |
| Technologies | ESP32, MQTT, Wi-Fi RSSI analysis |
| Filtering | Kalman filter, median filter, moving average |
